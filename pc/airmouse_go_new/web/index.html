Help & System Documentation

info About Air Mouse Pro

Air Mouse Pro is a state-of-the-art smartphone-based remote control platform. By reading gyroscope and accelerometer sensor values from your Android device, it streams movement coordinates directly to this host application via high-frequency protocols (UDP, TCP, WebSockets). The server then utilizes local hardware APIs to control the cursor position, click state, and mouse scroll speed.

Software Version v4.2.0 (Premium Enterprise)
Developers Google DeepMind / CA2 Engineering Team
Core Architecture Go (Backend) + Kotlin (Mobile client)

sensors How to Connect

  1. Open the Air Mouse Pro app on your Android device.
  2. Note the Server local IP addresses shown on this Dashboard (e.g. 192.168.1.X).
  3. Enter the target IP and choice of port (Default: 8081 for WebSockets / 8082 for TCP/UDP) on the phone.
  4. Tap Connect on your Android app.
  5. If Strict Authentication is enabled in Settings, approve the phone's connection request in the Devices section of this panel.

tune Feature Glossary

EMA Smoothing: Exponential Moving Average smoothing to filter sensor micro-jitters without introducing latency.
LSTM Sequence Predictor: Uses an ONNX neural model to perform deep-learning motion vector sequence predictions for smoother curves.
Humanizer B-Splines: Simulates physical muscle dynamics by injecting natural tremor frequency curves into linear transitions.
Particle Filter: Runs absolute spatial position calculations using a configurable number of particle estimation weights.

report_problem Troubleshooting

  • Unstable cursor movement: Try disabling LSTM Predictors or lowering BSpline Tremor levels in Settings.
  • High latency / Lag: Swap from TCP to UDP/WebSockets to bypass TCP congestion control mechanisms.
  • Connection rejected: Ensure your phone and PC are on the exact same Wi-Fi subnet. Check if firewalls block ports 8081/8082.
